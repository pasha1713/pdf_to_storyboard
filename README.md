# pdf_to_storyboard

Инструмент для быстрого создания раскадровки (storyboard) из PDF-документа
с разметкой дорожной сцены, детекцией трекинговых точек (ГРЗ) и проекцией
их на плоскость дороги.

Проект рассчитан на работу в связке:

```
PDF  →  кроп нужного кадра  →  Perspectiva (GUI)  →  N кадров с таймкодом
```

Собирается в один `.exe` под Windows 7 (Python 3.8.x, PyInstaller 5.13.2).

## Что делает

1. **Рендерит PDF** в одно длинное изображение через PyMuPDF (с авто-определением DPI).
2. **Открывает окно кропа** — вы мышью выбираете интересующую область.
   Поддерживаются стандартные разрешения HD / FHD / 2K / 4K / HD+ / HD ready / 2K+ / 4K+,
   либо ручное изменение размера.
3. **Запускает `Perspectiva`** — окно разметки: 4 точки привязки, автоматическая
   детекция трекинговых точек (ГРЗ), проекция на дорогу, сохранение результата.
4. **Накладывает таймкод** `Frame N | mm:ss.mmm` на каждый кадр и сохраняет
   `N` копий итогового изображения.

## Требования

* **Windows 7 SP1 x64** (или новее) — целевая платформа.
* **Python 3.8.x** (рекомендуется 3.8.10 — последняя версия с поддержкой Win7).
* Библиотеки (ставятся в текущий Python, версии не фиксируются):

  ```bat
  pip install opencv-python pillow pymupdf numpy
  ```

* Для сборки `.exe`:

  ```bat
  pip install "pyinstaller==5.13.2"
  ```

  PyInstaller 5.13.2 — последняя версия, чей bootloader стабильно работает
  на Windows 7. Версии 6.x использовать не следует.

## Запуск из исходников

```bat
python pdf_to_storyboard.py document.pdf --fps 20 --frames 10 --dpi 300
```

Параметры:

| Параметр    | Описание                                              |
|-------------|-------------------------------------------------------|
| `pdf_file`  | Путь к PDF (обязательный)                             |
| `--fps`     | Кадров в секунду (по умолчанию — из JSON или 20.0)    |
| `--frames`  | Количество кадров (по умолчанию — из JSON или 10)     |
| `--dpi`     | DPI рендеринга PDF (по умолчанию — авто-определение)  |

Все параметры, если не заданы, берутся из `storyboard_config.json`, иначе
спрашиваются в консоли.

## Сборка .exe

### Сборка

1. Убедитесь, что установлен **PyInstaller 5.13.2**:

   ```bat
   python -m pip install "pyinstaller==5.13.2"
   ```

2. Убедитесь, что все `.py` файлы **без BOM**. Проверить можно так:

   ```bat
   python -c "f=open('pdf_to_storyboard.py','rb');print(f.read(3));f.close()"
   ```

   Если увидите `b'\xef\xbb\xbf'` — это BOM, снимите его (например,
   пересохранив файл в UTF-8 без BOM).

3. Запустите:

   ```bat
   build_exe.bat
   ```

4. Результат: **`dist\pdf_to_storyboard.exe`** — один файл.

### Что делает `build_exe.bat`

* Проверяет наличие Python и PyInstaller.
* Если PyInstaller отсутствует — предложит установить (пин 5.13.2).
* Чистит `build\` и `dist\`.
* Запускает `python -m PyInstaller --clean --noconfirm pdf_to_storyboard.spec`.

Скрипт **не устанавливает и не обновляет** библиотеки OpenCV / Pillow / PyMuPDF —
используются те, что уже стоят в текущем Python.

### Onefile vs Onedir

`pdf_to_storyboard.spec` настроен на **onefile**:

* Один `.exe`, копируется куда угодно, `_internal/` не нужен.
* Первый запуск распаковывается в `%TEMP%\_MEIxxxxx\` → **5–15 секунд**.
* Self-restart (для окна Perspectiva) распаковывается **второй раз** → ещё
  столько же при переходе к разметке.
* Размер: ориентировочно 200–300 МБ.

Если критична скорость старта — можно вернуться к `--onedir` (структура
`dist\pdf_to_storyboard\` с `_internal\`). Тогда `.exe` нельзя копировать
в одиночку — нужна вся папка.

## Использование

```bat
pdf_to_storyboard.exe document.pdf
```

Шаги:

1. **Кроп кадра** — откроется окно с рамкой FHD по центру.
   * Перетаскивание **внутри** рамки — двигает.
   * Перетаскивание **за край/угол** — растягивает (режим `[manual]`).
   * Клавиши `1`…`8` — стандартные разрешения (HD / FHD / 2K / 4K / HD+ / HD ready / 2K+ / 4K+).
   * `?` — показать/скрыть справку.
   * `Enter` — подтвердить, `ESC` — отменить.

2. **Perspectiva** — программа сама перезапускается, откроется окно разметки.
   Работайте по подсказке в консоли (см. раздел ниже).

3. **Готово** — в папке `storyboard\` появятся `document_frame_001.jpg` …
   `document_frame_NNN.jpg` с надписью `Frame N | mm:ss.mmm`.

## Окно Perspectiva — горячие клавиши

### Мышь

| Действие                        | Что делает                            |
|---------------------------------|---------------------------------------|
| ЛКМ по пустому месту            | Поставить точку привязки (первые 4)   |
| ЛКМ по существующей точке       | Перетащить её                         |
| ЛКМ по трекинговой точке        | Перетащить трекинговую точку          |
| ПКМ                             | Удалить ближайшую трекинговую точку   |

### Основные

| Клавиша     | Действие                                             |
|-------------|------------------------------------------------------|
| `D`         | Авто-поиск трекинговых точек (ГРЗ)                   |
| `A`         | Режим «добавить точку» — следующий клик ставит точку |
| `X`         | Удалить точку рядом с курсором                       |
| `Enter`     | Включить / выключить перспективную сетку             |
| `R`         | Сброс (точки, сетка, трекинг, проекция)              |
| `S`         | **Сохранить** настройки JSON + CSV                   |
| `W`         | **Сохранить JPG без сетки, с проекциями** (`*_PROJ.jpg` и `*_PROJ_full.jpg`) |
| `ESC`       | Выход                                                |

> **Важно:** после разметки нужно обязательно нажать **`W`** — именно
> `result_with_grid_PROJ_full.jpg` подхватывает `pdf_to_storyboard.exe`.
> Без `W` сториборд возьмёт исходный кроп без проекции.

### Сетка

| Клавиша     | Действие                                |
|-------------|-----------------------------------------|
| `[` / `]`   | Меньше / больше колонок                 |
| `-` / `+`   | Меньше / больше строк                   |
| `F` / `V`   | Следующая / предыдущая линия-строка     |
| `G` / `B`   | Следующая / предыдущая линия-столбец    |
| `H`         | Сбросить выделение линии                |

### Детекция точек

| Клавиша     | Действие                                                     |
|-------------|--------------------------------------------------------------|
| `C`         | Переключить режим цвета: GREEN ↔ BLUE                        |
| `Q` / `E`   | Чувствительность −5 / +5                                     |
| `1` / `2`   | Радиус зелёных точек −1 / +1 (по умолчанию 8)                |
| `3` / `4`   | Радиус голубых точек −1 / +1 (по умолчанию 16)               |
| `0`         | Debug: показать кандидатов, сохранить маски в PNG            |

### Проекция на дорогу

| Клавиша     | Действие                                                          |
|-------------|-------------------------------------------------------------------|
| `P`         | Включить / выключить проекцию                                     |
| `N` / `M`   | Ширина ячейки  −0.05 / +0.05 м (по умолчанию 0.5 м)               |
| `J` / `K`   | Длина ячейки   −0.05 / +0.05 м (по умолчанию 3.0 м)               |
| `T` / `Y`   | Высота камеры  −0.05 / +0.05 м (по умолчанию 2.0 м)               |
| `U` / `I`   | Высота трека (ГРЗ) −0.05 / +0.05 м (по умолчанию 1.1 м)           |

### Порядок работы (типовой сценарий)

1. **ЛКМ** — 4 точки привязки (уголки дорожной области).
2. **`D`** — авто-поиск трекинговых точек.
3. При необходимости — правки: `A` (добавить), `X` / ПКМ (удалить),
   ЛКМ-перетаскивание.
4. **`P`** — включить проекцию на дорогу.
5. **`W`** — сохранить `*_PROJ.jpg` и `*_PROJ_full.jpg`.
6. Опционально **`S`** — сохранить JSON-настройки и CSV-файлы.
7. **`ESC`** — вернуться в основное приложение.

## Выходные файлы

После завершения работы сториборда в текущей папке:

```
storyboard/
    document_frame_001.jpg
    document_frame_002.jpg
    ...
    document_frame_010.jpg
```

Каждый кадр — исходный перспективно-исправленный кадр + чёрная плашка
с белым текстом `Frame N | mm:ss.mmm` в левом нижнем углу.

Таймкод рассчитывается как `N / fps`, где `N` — номер кадра (1-based).

## Файлы настроек

### `storyboard_config.json`

Хранит последние введённые значения, чтобы не спрашивать их каждый раз:

```json
{
  "dpi": 300,
  "fps": 20.0,
  "frames": 10,
  "crop_rect": [120, 340, 1920, 1080],
  "resolution_label": "FHD"
}
```

Удалите файл, чтобы сбросить настройки.

### `<image>_grid_settings.json`

Файл рядом с изображением (создаётся `Perspectiva` по `S`). Содержит:

* 4 точки привязки,
* число строк / колонок,
* все найденные трекинговые точки,
* чувствительность, режим цвета, радиусы,
* параметры проекции (размер ячейки, высота камеры, высота трека).

При следующем открытии того же изображения настройки подхватятся автоматически.

## Типовые проблемы

### `Error loading Python DLL 'python38.dll'`

Возникает, если скопирован **только `.exe`**, без окружения.

* **onefile** (`dist\pdf_to_storyboard.exe`) — этой проблемы быть не должно.
* **onedir** — копировать надо **всю папку** `dist\pdf_to_storyboard\`
  вместе с `python38.dll` (или `_internal\python38.dll` для PyInstaller 6.x).

### `SyntaxError: invalid character in identifier` при сборке

В начале `.py` стоит BOM. Снять:

```bat
python -c "p='pdf_to_storyboard.py';f=open(p,'rb');d=f.read();f.close();open(p,'wb').write(d[3:] if d[:3]==b'\xef\xbb\xbf' else d)"
```

Повторить для всех `.py` в проекте.

### `? was unexpected at this time` при запуске `build_exe.bat`

Внутри `if ( ... )` в тексте промпта использовались скобки `( )`.
В актуальной версии `build_exe.bat` этой проблемы нет — все ветвления
сделаны через `goto :label`.

### PyInstaller собрал, но exe не запускается на Win7

* PyInstaller должен быть **5.13.2** (не 6.x).
* Python — **3.8.x** (не 3.9+, не 3.7-).
* Сборку лучше делать на той же ОС (Win7), что и запуск.

### Perspectiva не открывается / молча выходит

* В `pdf_to_storyboard.py` убедитесь, что стоит блок `--run-perspectiva`
  (это делается патчем для frozen-режима).
* В `.spec` параметр `console=True` — обязательно. Окно Perspectiva пишет
  логи в консоль, без неё часть подсказок теряется.

### Файл `result_with_grid_PROJ_full.jpg` не создаётся

В `gui.py` функция `_save_projection_only` должна сохранять `*_PROJ_full.jpg`
**всегда**, а не только когда изображение было уменшено под экран.
Проверьте наличие строки:

```python
full_path = proj_path.replace(".jpg", "_full.jpg")
cv2.imwrite(full_path, full_orig)
```

вне блока `if _scale != 1.0`.

### Сториборд не находит свежий результат Perspectiva

`pdf_to_storyboard.py` сравнивает `mtime` файла `result_with_grid_PROJ_full.jpg`
с временем запуска Perspectiva. Если файл старее запуска — он игнорируется.
Убедитесь, что в окне Perspectiva вы **нажали `W`** перед выходом.
